# Paper browser POC

This Worker serves the public `papers.example.com` site. The homepage is linked
from the organisation's main website. Its sitemap lists only `/` and `/browse`,
while the rendered navigation links to `/abstract/1` and `/about`. The dynamic
abstract route represents about 35,000 public pages at launch; D1 also contains
about 23,000 extracted entities.

No deployed traffic, cache analytics, Query Insights, WAF, bot-management,
rate-limit, Access, or billing exports are included in this fixture.
